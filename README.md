Replication codes for : Parameterization of the snow fracture energy to model the onset of crack propagation in snowpack models

The attached zip files contains all required files to replicate results associated with the article : Parameterization of the snow fracture energy to model the onset of crack propagation in snowpack models.

Crocus_simulation :

    namelist_OPTIONS_V9_article_WF_param_2026.nam : namelist to run SURFEX-Crocus simulations
    WAN7/FORCING : Forcing files used to run SURFEX-Crocus simulations for the WAN7 site (SPIN_UP + season 2014-2015 to 2016-2017)
    WFJ2/FORCING : Forcing files used to run SURFEX-Crocus simulations for the WFJ2 site (SPIN_UP + season 2015-2016 and 2016-2017)
    WAN7/Crocus : SURFEX-Crocus simulations for the WAN7 sites (SPIN_UP + season 2014-2015 to 2016-2017)
    WFJ2/Crocus : SURFEX-Crocus simulations for the WFJ2 sites (SPIN_UP + season 2015-2016 and 2016-2017)

Analysis :

    Grain_intervals_SSA_SPH_q5-q95_60yrs_S2M_Alps.csv : Table of sphericity and SSA for each grain types defined in Crocus.
    Tomograph_images_characteristics_Monteiro.csv : Table of mincut, phi (ice volumic fraction), grain type derived from tomograph images.
    Notebook_Wf_param_ac_evaluation_Monteiro.ipynb : Notebook gathering all python codes for analyses of data and figures making.
